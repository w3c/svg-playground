# Contributing to the SVG Playground

Pages in this repository are test pages and examples, not specification text. Anyone can contribute: open a pull request with a new probe, a new case in an existing probe, or a result file from a browser that has not been run yet.

By contributing you agree to license your contribution under the [W3C Software and Document License](LICENSE.md).

The layout and the rules for probes and results are in the [README](README.md).

Spec changes go to https://github.com/w3c/svgwg, and tests that encode a decision go to https://github.com/web-platform-tests/wpt.
